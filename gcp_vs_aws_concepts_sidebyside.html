GCP vs AWS concepts side by side — organized by topic category

GCP (GCDL)
AWS (AIF-C01)
Managed LLM / Foundation model platform most tested
Vertex AI
Unified ML platform — train, deploy, monitor. Hosts Gemini models + third-party models.
Amazon Bedrock
Managed FM service. Access Claude, Llama, Titan, Mistral, Cohere via API. No infra to manage.
AI assistant / Copilot product
Gemini (formerly Bard)
Google's LLM family. Gemini Pro, Ultra, Nano. Accessible via Vertex AI or direct API.
Amazon Q
Q Business (enterprise search/chat), Q Developer (code assistant). Know both variants.
RAG / Knowledge retrieval most tested
Vertex AI Search
Grounding + RAG on enterprise docs. Also called "Vertex AI Agent Builder" in newer docs.
Bedrock Knowledge Bases
Connect S3 docs to LLMs via embeddings + vector search. Fully managed RAG pipeline.
Agents / Orchestration
Vertex AI Agents
Build multi-step AI agents using Gemini. Integrates with tools and APIs.
Agents for Amazon Bedrock
Orchestrate multi-step tasks with FM + tools + Lambda actions. Know action groups concept.
ML model training & AutoML
Vertex AI AutoML
No-code model training for tabular, image, text, video data.
SageMaker Canvas / Autopilot
Canvas = no-code ML. Autopilot = automated model selection & tuning.
Model monitoring & bias detection responsible AI
Vertex AI Model Monitor
Detect data drift, skew, and feature attribution changes in deployed models.
SageMaker Clarify
Detects bias in data and models. Provides explainability reports (SHAP values).
Pre-built AI APIs (vision, speech, NLP)
Cloud Vision, Speech-to-Text, Natural Language, Translation
Individual APIs for each modality. Know which API does what.
Rekognition, Transcribe, Comprehend, Translate, Polly, Textract
Rekognition=images/video, Transcribe=speech→text, Comprehend=NLP, Polly=text→speech, Textract=OCR.
Vector / Embedding search
Vertex AI Vector Search (Matching Engine)
Managed vector database for similarity search at scale.
OpenSearch Service / pgvector on RDS
AWS uses OpenSearch or Aurora pgvector for vector storage. No dedicated vector DB service.
Both exams test: what is an embedding, what is RAG, difference between fine-tuning vs prompting, hallucination causes, and responsible AI principles. These concepts are cloud-agnostic — learn once, apply to both.
GCP
AWS
Virtual machines
Compute Engine
GCP's IaaS VM service. Choose machine type, OS, region. Preemptible VMs = cheaper but interruptible.
Amazon EC2
AWS VMs. Know instance families (T=general, M=memory, C=compute, G=GPU). Spot = cheap + interruptible.
Serverless functions frequently tested
Cloud Functions / Cloud Run
Functions = event-triggered code. Cloud Run = containerized apps, scales to zero.
AWS Lambda
Event-triggered functions. Pairs with API Gateway for REST endpoints. Max 15 min timeout.
Managed containers / Kubernetes
Google Kubernetes Engine (GKE)
Managed Kubernetes. GKE Autopilot = fully managed node provisioning.
Amazon EKS / ECS
EKS = managed Kubernetes. ECS = AWS-native container orchestration (simpler than K8s).
App platform / PaaS
App Engine
PaaS — deploy code without managing infrastructure. Standard vs Flexible environments.
AWS Elastic Beanstalk
PaaS wrapper around EC2. Upload code, AWS handles scaling and deployment.
GCP
AWS
Object storage most tested
Cloud Storage (GCS)
Buckets for unstructured data. Storage classes: Standard, Nearline, Coldline, Archive.
Amazon S3
Industry standard. Storage classes: Standard, IA, Glacier. Know lifecycle policies and versioning.
Block storage (VM disks)
Persistent Disk / Hyperdisk
Attached to Compute Engine VMs. Zonal or regional. SSD or HDD.
Amazon EBS
Elastic Block Store — attached to EC2. gp3 = general purpose SSD. io2 = high IOPS.
File / shared storage
Filestore
Managed NFS file storage. Shared across multiple VMs.
Amazon EFS
Elastic File System — managed NFS, scales automatically. For shared access across EC2.
GCP
AWS
Data warehouse frequently tested
BigQuery
Serverless data warehouse. BigQuery ML lets you run ML models with SQL. Columnar storage.
Amazon Redshift
Managed data warehouse. Columnar storage. Redshift ML integrates SageMaker for in-DB ML.
Managed relational DB
Cloud SQL / Cloud Spanner
Cloud SQL = managed MySQL/PostgreSQL. Spanner = globally distributed relational DB.
Amazon RDS / Aurora
RDS = managed MySQL/PostgreSQL/Oracle. Aurora = AWS-native, 5x faster than MySQL.
NoSQL / document DB
Firestore / Bigtable
Firestore = document DB (like MongoDB). Bigtable = wide-column, low latency, IoT/analytics.
Amazon DynamoDB
Key-value + document NoSQL. Single-digit ms latency. Know partition keys, sort keys, GSI.
Data pipeline / ETL
Cloud Dataflow / Dataproc
Dataflow = Apache Beam managed (stream+batch ETL). Dataproc = managed Spark/Hadoop.
AWS Glue / EMR
Glue = serverless ETL + data catalog. EMR = managed Spark/Hadoop clusters.
GCP
AWS
Virtual private network frequently tested
VPC (Virtual Private Cloud)
GCP VPCs are global by default (span regions). Subnets are regional.
Amazon VPC
AWS VPCs are regional. Know subnets (public vs private), route tables, NAT gateway, IGW.
Load balancing
Cloud Load Balancing
Global HTTP(S), TCP, UDP. Google's LB is global by default — single anycast IP.
Elastic Load Balancer (ALB/NLB/CLB)
ALB = layer 7 (HTTP). NLB = layer 4 (TCP). Know when to use each.
CDN
Cloud CDN
Integrates with Cloud Load Balancing. Cache static content at Google's edge nodes.
Amazon CloudFront
Global CDN with edge locations. Integrates with S3, EC2, API Gateway. Supports Lambda@Edge.
DNS
Cloud DNS
Managed authoritative DNS. Low-latency global serving.
Amazon Route 53
DNS + domain registration + health checks + routing policies (latency, failover, geolocation).
GCP
AWS
Identity & access management most tested
Cloud IAM
Roles, members, policies. Know primitive roles (Owner/Editor/Viewer) vs predefined vs custom. Service accounts for apps.
AWS IAM
Users, groups, roles, policies (JSON). Know least privilege. IAM roles for EC2/Lambda = no hardcoded creds.
Secrets / key management
Secret Manager / Cloud KMS
Secret Manager = store API keys/passwords. KMS = encryption key management.
AWS Secrets Manager / KMS
Secrets Manager = rotate + store secrets. KMS = create and control encryption keys. Know difference from Parameter Store.
Threat detection / Security monitoring
Security Command Center
Centralized security posture. Detects misconfigs, vulnerabilities across GCP resources.
Amazon GuardDuty
Threat detection using ML on CloudTrail, VPC flow logs, DNS logs. Know it's ML-based.
Data privacy / PII detection
Cloud DLP (Data Loss Prevention)
Discover, classify, mask sensitive data (PII, credit cards) in GCS, BigQuery, Datastore.
Amazon Macie
Uses ML to find and protect sensitive data in S3. Classifies PII automatically.
Audit logging
Cloud Audit Logs
Admin activity, data access, system events. Stored in Cloud Logging.
AWS CloudTrail
Records every API call in AWS. Who did what, when, from where. Essential for compliance.
GCP
AWS
CI/CD pipeline
Cloud Build / Cloud Deploy
Cloud Build = CI (build, test). Cloud Deploy = managed CD to GKE, Cloud Run, GCE.
CodePipeline / CodeBuild / CodeDeploy
CodePipeline = orchestrator. CodeBuild = compile/test. CodeDeploy = deploy to EC2/Lambda/ECS.
Container registry
Artifact Registry
Store Docker images, Maven, npm packages. Replaced Container Registry.
Amazon ECR
Elastic Container Registry. Private Docker image store. Integrates with ECS/EKS.
Monitoring & logging ops questions
Cloud Monitoring / Cloud Logging
Monitoring = metrics, dashboards, alerts. Logging = log storage and analysis (Cloud Logging formerly Stackdriver).
Amazon CloudWatch
Metrics, logs, alarms, dashboards in one service. Know CloudWatch Logs Insights for querying logs.
Infrastructure as code
Deployment Manager / Terraform
Deployment Manager = GCP-native IaC. Terraform = preferred multi-cloud IaC in practice.
AWS CloudFormation / Terraform
CloudFormation = AWS-native IaC (YAML/JSON templates). CDK = write IaC in Python/JS/Java.
Messaging / event streaming
Pub/Sub
Managed message queue. Decouples producers and consumers. At-least-once delivery.
SQS / SNS / EventBridge
SQS = queue. SNS = pub/sub notifications. EventBridge = event bus for routing events between services.
